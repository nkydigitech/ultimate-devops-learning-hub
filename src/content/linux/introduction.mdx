# 🚀 Why Linux?

Linux is an **open-source operating system**. Unlike Windows, it's built for stability, security, and automation.

<Tip title="Why This Matters">
If your goal is to become a DevOps Engineer, Linux is your foundation. Almost every cloud platform, container platform, and automation tool you will use runs on Linux.
</Tip>

### Where is Linux Used?

| Sector | Usage |
|------------|---------------|
| **Cloud Computing** | AWS, Azure, Google Cloud |
| **Containers** | Docker, Podman, Kubernetes |
| **Web Servers** | Nginx, Apache, Node.js |
| **Databases** | MySQL, PostgreSQL, Redis |

# 💼 Interview Preparation

<InterviewPrep question="Why do DevOps engineers prefer Linux over Windows for production environments?">
  Linux offers several advantages for DevOps:
  - **Open Source:** No licensing costs and full control over the OS.
  - **Security:** Permissions and user management are built-in from the ground up.
  - **Automation:** The command-line interface (CLI) is extremely powerful and easily scriptable.
  - **Performance:** Linux is lightweight and can run without a graphical user interface (GUI), saving resources for applications.
</InterviewPrep>

# 🧪 Hands-on Practice

<Exercise title="Your First Linux Interaction">
  <div slot="tasks">
    1. Open your terminal (WSL, Linux, or macOS).
    2. Run the `whoami` command to see your current user.
    3. Run the `uname -a` command to see system information.
    4. Print a welcome message using `echo`.
  </div>
  
  <div slot="solution">
    <Terminal 
      command="whoami && uname -a && echo 'Hello DevOps!'" 
      output={`student\nLinux devops-hub 5.15.0-generic #54-Ubuntu SMP... x86_64\nHello DevOps!`}
    />
  </div>
</Exercise>

<Warning title="Don't Memorize Commands">
One of the biggest mistakes beginners make is trying to memorize hundreds of Linux commands. Instead, understand the *why* and the *how*. The commands will become natural through practice.
</Warning>
