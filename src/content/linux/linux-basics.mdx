# What is the Terminal?

Unlike Windows, where many tasks are done by clicking icons, Linux administrators spend much of their day in the **terminal** — typing commands that talk directly to the operating system. Learning the terminal is the single most important Linux skill.

---

# Your First Commands

**Print working directory** — where am I?

<Terminal command="pwd" output="/home/student" />

`pwd` stands for **Print Working Directory**. It tells you exactly where you are.

**List files:**

<CommandBlock command={`ls        # list files
ls -l     # long format (permissions, size, date)
ls -la    # include hidden files`} />

**Change directory:**

<CommandBlock command={`cd Documents   # move into a folder
cd ..          # go back one level
cd             # return to your home directory`} />

---

# Creating and Removing Things

<CommandBlock command={`mkdir linux-practice   # create a folder
cd linux-practice      # enter it
touch notes.txt        # create an empty file
ls                     # verify it exists
rm notes.txt           # remove the file
cd ..                  # leave the folder
rmdir linux-practice   # remove the (empty) folder`} />

<Warning title="rm has no undo">
There is no Recycle Bin on the Linux command line. `rm` deletes immediately and permanently. Double-check the path before you press Enter — especially with `rm -r`.
</Warning>

---

# Relative vs Absolute Paths

- **Relative path** — starts from where you currently are: `cd Documents`
- **Absolute path** — starts from the root `/`: `cd /home/student/Documents`

Professional engineers use both every day.

---

# Real DevOps Example

When you log into a fresh AWS EC2 server, the first three commands most engineers type are:

<Terminal

# ⚠ Common Beginner Mistakes

<Warning title="Watch Out For These">
- **Missing spaces:** `cdDocuments` is wrong — it's `cd Documents`.
- **Case sensitivity:** `Documents`, `documents`, and `DOCUMENTS` are three different names in Linux.
</Warning>

# 💼 Interview Preparation

<InterviewPrep question="What is the difference between an absolute path and a relative path?">
  An **absolute path** always starts from the root directory `/` and describes the full location regardless of where you are — for example `/home/student/Documents`.

  A **relative path** is interpreted from your current working directory — for example `Documents` or `../logs`.

  Absolute paths are unambiguous and are preferred in scripts and cron jobs; relative paths are shorter and convenient for interactive work.
</InterviewPrep>
