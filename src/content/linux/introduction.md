# What is Linux?

Linux is an **open-source operating system**.

An operating system (OS) is software that manages your computer's hardware and allows applications to run.

Examples include:

- Windows
- macOS
- Linux

Unlike Windows, Linux is free, open-source, secure, and highly customizable.

Today Linux powers:

- Cloud servers
- Websites
- Supercomputers
- Android phones
- Kubernetes clusters
- Docker containers
- Smart TVs
- Internet infrastructure

In fact...

More than **96% of the world's top one million web servers run Linux.**

# Linux Distributions

Linux comes in many versions called **distributions** (or "distros").

Some popular ones include:

## Ubuntu

Most beginner-friendly.

Widely used for learning DevOps.

---

## Debian

Stable and reliable.

Ubuntu is built from Debian.

---

## Rocky Linux

Enterprise Linux.

Popular replacement for CentOS.

---

## Red Hat Enterprise Linux (RHEL)

Used by many large companies.

Requires a subscription.

---

## Fedora

Latest Linux technologies.

Great for developers.

---

## Arch Linux

Advanced users.

Highly customizable.
