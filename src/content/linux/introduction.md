# Introduction to Linux

Linux is the operating system that powers most of the world's servers, cloud platforms, containers, and supercomputers.

## Why Learn Linux?

- Used by AWS, Azure, and Google Cloud
- Powers Kubernetes and Docker
- Essential for DevOps Engineers
- Free and Open Source

## What You Will Learn

- Linux distributions
- Terminal basics
- File system
- Users and permissions
- Networking
- Shell scripting
